Fetch and assemble the TSIE boot artifacts in one go: OpenSBI firmware,
EDK II (UEFI) firmware, and an Alpine kernel plus initramfs.

Read this before changing the script:
  * Versions are always discovered at run time, never hard-coded. Alpine's
    packages move quickly and a pinned URL eventually 404s (the linux-lts-6.18.44
    URL this README once carried was already dead on 2026-09-26).
  * Everything lands in gitignored directories (`firmware/`, `tmp/`) and must
    never be committed: these are GPL-2.0 and other third-party artifacts,
    while this project is Apache-2.0.
  * Every download retries. This machine's network reaches dl-cdn and
    deb.debian.org only intermittently - the same host succeeds one minute and
    times out 21 seconds later - so retrying is not optional.
  * GitHub release assets cannot be fetched directly here (github.com answers,
    but objects.githubusercontent.com, which the 302 points at, times out), so a
    mirror is needed. A mirror is a proxy relay, so the script asks first
    (--mirror pre-authorises it).

Usage:
  tools/bootstrap.sh                 # interactive: asks about the mirror if GitHub is unreachable
  tools/bootstrap.sh --mirror        # pre-authorise the mirror (unattended)
  tools/bootstrap.sh --no-mirror     # forbid the mirror; take OpenSBI from local files only
  tools/bootstrap.sh --no-edk2       # skip EDK II (saves about 70 MB)
  tools/bootstrap.sh --decompress    # pre-agree to unpacking the initramfs (unattended)
  tools/bootstrap.sh --no-decompress # do not unpack; keep only the .cpio.gz
  tools/bootstrap.sh --alpine v3.24  # pin the Alpine branch (default latest-stable)
  tools/bootstrap.sh --dir DIR       # use a different output directory (default tmp/boot)
  tools/bootstrap.sh --lang en       # English messages (default: follow the system locale)

EDK II needs a .deb unpacked (an ar archive): the bsdtar or 7-Zip already on
the system is preferred. If neither exists the script explains that it would
download a static bsdtar from a third-party repository, provided AS IS with no
warranty, and only continues if you agree.

Dependencies (what happens when one is missing):
  required  curl / tar / sha256sum  bundled with Git Bash
  required  node + tsx              tools/initramfs.ts packs the initramfs, and
                                    tsx is a devDependency (run npm install
                                    first). That step never touches the disk: it
                                    reads mode and linkname straight from the
                                    tar header, so neither "Windows cannot
                                    create symlinks" nor "Windows cannot store
                                    execute bits" affects it. Python is no
                                    longer needed.
  optional  bsdtar / 7-Zip          needed only for EDK II, because a .deb is an
                                    ar archive and Git Bash's GNU tar cannot read
                                    ar. An installed one is used as-is - Windows
                                    ships bsdtar as C:\Windows\System32\tar.exe.
                                    With neither present the script asks before
                                    borrowing a static bsdtar into a temporary
                                    directory, which it deletes afterwards.
  not needed xz                     OpenSBI ships as .tar.xz, but tar decompresses
                                    it through liblzma on its own.
